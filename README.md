# anvil

Who in the guild can craft what. A Discord bot and a page for WoW Forever guilds, at
https://anvil.fayelore.com. A sister to [muster](https://github.com/fayedintoyou/muster).

Everyone logs their professions once, in Discord, and then anyone can ask who can make something. There's
no addon to install and nothing to export from the game:

- **`/prof set`**: a character's profession and skill. Every recipe a trainer teaches up to that skill counts
  on its own, so for most recipes that's all there is to log.
- **`/recipe add`**: the recipes a skill doesn't cover, like drops, vendor patterns, quest rewards and
  campsite recipes. Autocomplete only offers ones the character has the skill for and still needs to log.
- **`/recipe bulk`** and **`/recipe edit`**: for a lot at once. Bulk opens a box to paste a list into, one
  recipe per line ("Pattern:" and the like are fine); edit sends a private link, good for two hours, to a
  checklist of every recipe the character could have.
- **`/want`**: asks for something in the channel and pings the people whose characters can make it.
- **`/whocan`**: who can make something, answered in the channel. It names who has logged it or has the
  skill for it, and when a recipe nobody has turns up, who has the skill to learn it.
- **`/crafters`**, **`/mine`**: everyone in a profession; what you've logged.
- **`/anvil`**: how to use it, and the guild's page: every crafter's skill, a search, and the recipes nobody
  has yet, to farm or buy toward. The link unfurls in Discord.
- **`/board`**: a message in a channel of your choosing, with every profession's crafters, that anvil edits
  itself as people log things. Manage Server only.
- Recipe names link to Wowhead's WoW Forever database. Characters nobody has updated in 30 days show faded on
  the page and in italics on the board, since their skill may be behind.
- **Your characters are yours**: only you, or someone with Manage Server, can change them.
- **Name your character once**: leave `character:` out and anvil uses the one you last changed (or your
  only one). `/prof forget` always needs the name.

The recipe list holds 2,228 recipes across the twelve professions, built from two MIT-licensed addons'
data (see [NOTICE.md](NOTICE.md)). `node scripts/audit.mjs` checks it against Wowhead's WoW Forever
database: every recipe there under the same name, and the same skill on its pattern or plans.

## How it's built

- `src/core/`: plain TypeScript with no DOM: the professions, the recipe list and its search, who can
  make what, validation. Shared by the page and the Worker.
- `src/core/recipes.json`: generated by `npm run recipes` (`scripts/recipes.mjs`).
- `worker/`: the Cloudflare Worker. `index.ts` takes Discord's interactions (each checked against the
  application's signing key), serves the API and fills in guild pages' link previews; `handlers.ts` runs
  the commands; `guild-object.ts` is the Durable Object holding one Discord server's characters.
  `commands.ts` is the command list that `npm run register` sends to Discord.
- `src/app/`: the guild page, in React, with the room's look.
- `e2e/run.mjs`: plays Discord against `wrangler dev`, signing interactions as Discord does for three
  people, then checks the guild page in real Chrome at phone and desktop sizes. Screenshots go to
  `e2e/shots/`.

## Working on it

```sh
npm ci
npm run dev        # build the page, then serve everything on http://localhost:8787
npm test           # checks on the recipe list
npm run typecheck
npm run test:e2e   # builds, starts its own wrangler dev, drives Chrome (CHROME=/path/to/chrome)
npm run recipes    # rebuild src/core/recipes.json from the pinned addon commits
```
